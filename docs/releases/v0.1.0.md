First release of PageWeave, a free document studio for Windows that works on your own computer.

- View, search, organize, edit, fill, redact, protect, sign and compare PDF files. Originals are never changed; every result is a new, verified file.
- Convert PDF to Word, PowerPoint, Excel/CSV tables, text and images; images to PDF; open Office files when LibreOffice is installed.
- Make scans searchable (OCR), straighten them and turn them upright.
- Translate between English, German, French, Spanish and Italian; all languages are included in the full download.
- Read documents aloud with the computer's voices, the spoken word highlighted.
- Updates: PageWeave checks for new versions at startup and installs them from Settings ▸ Updates. An update downloads only the program (about 40 MB); languages and settings are kept.

Download PageWeave_0.1.0_x64-setup.exe (the update-setup file is for in-app updates).

Known limits: early release. The installer is not yet signed with a Windows certificate, so SmartScreen may ask you to confirm. See the README for the full list of limitations.
