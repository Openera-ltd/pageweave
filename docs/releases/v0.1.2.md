PageWeave 0.1.2 — Design Studio, more translation and editing, and a full offline download.

Download **PageWeave_0.1.2_x64-setup.exe** (the update-setup file is for in-app updates). It installs everything — every translation language, text recognition, LibreOffice for Office files and the WebView2 runtime — so a computer without internet can use every feature. LibreOffice is unpacked into your user folder during installation. If you have 0.1.0 or 0.1.1, PageWeave offers this update in Settings ▸ Updates; your languages and settings are kept.

New
- Design Studio: rebuild a flat design (a PDF page or a picture) as editable text, shapes and pictures; edit, align, group, rotate, crop and export to SVG, PDF or PNG.
- Translation: Portuguese added and every pair translated directly; translate into a PDF that keeps the layout, optionally with each page next to its translation; a glossary for fixed terms; several files at once.
- Comments and markup: move, resize and recolour existing annotations; choose the colour of new highlights and notes.
- Edit mode: resize pictures; turned text is editable in place.
- Password-protected files: changes the owner allowed are possible, and new files keep the same password and restrictions.
- Forms: radio groups and lists can be emptied; IRS-style hybrid forms fill through their standard form.
- Pictures in WebP, TIFF, GIF and BMP are accepted everywhere pictures are.
- The top bar groups tools and moves what does not fit into More tools; the Studio's bar stays usable down to the smallest window.

Fixed
- Pictures drawn inline in a page are kept when editing or translating it; colours are kept when pages are rewritten.
- Combine keeps bookmarks and the first file's properties and names every file it cannot open; Create PDF from images names every unusable picture.
- Empty or mislabelled Office files are refused instead of becoming blank PDFs.
- Prose columns are no longer exported as tables.

Known limits: early release. The installer is not signed with a Windows certificate, so SmartScreen may ask you to confirm ("More info" → "Run anyway"). Tested on GitHub's Windows runners, not yet on a range of real PCs. See the README for the full list of limitations.
